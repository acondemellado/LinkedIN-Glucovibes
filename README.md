# LinkedIN-Glucovibes

Repositorio público de imágenes y materiales de publicaciones de LinkedIn de Glucovibes y SYNC2.

## Estructura

- `SYNC2/`: infografías de la serie SYNC2 by Glucovibes.

Las publicaciones se redactan y validan antes de su programación en Buffer. Cada comparación SYNC2 representa a **la misma persona o al mismo equipo** en dos situaciones cotidianas distintas, respetando la identidad visual Glucovibes.
